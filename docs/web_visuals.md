# Web Visuals

## Markdown

Markdown is a plain text syntax to write single-page, single-column, left-align Web documents. With several symbols, Markdown marks italic, bold, heading, list, link, image, etc. John Gruber and Aaron Swartz created the [syntax]("https://daringfireball.net/projects/markdown/syntax") and the Perl [code]("https://daringfireball.net/projects/downloads/Markdown_1.0.1.zip") for text-to-HTML conversion in 2004.

### CommonMark

CommonMark is a specification of Markdown that available in many Web sites. You needn't convert to HTML by yourself. In 2014, a group of Markdown fans _(John MacFarlane of *Pandoc*, David Greenspan of *Meteor*, Vicent Marti of *GitHub*, Neil Williams of *Reddit*, Benjamin Dumke-von der Ehe of *Stack Overflow / Stack Exchange*, Jeff Atwood of *Discourse*)_ started the [syntax]("https://commonmark.org/help/") and the C [code]("https://github.com/commonmark/cmark").
    
- All links/anchors are underlined and blue
- Every block/inline code is inside a gray rectangle
- Every block quote is indented and a gray bar at the left

### GitHub Markup

GitHub is a remote server for Git repositories and a hub to cooperate in writing code or to share code. To write at GitHub with more ease, they expand CommonMark by unicode emoji, alert, color dot, table, task list, etc. Its expanded [syntax]("https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax") and Ruby [code]("https://github.com/github/markup").

- All features of CommonMark
- Every heading is underlined with a 100% width gray line
- All headings have Auto Anchors
- Alert: Note, Tip, Important, Warning, Caution
- Color Dot
- Task List
- Table:
    - header is bold and mid
    - half table rows are gray
    - all strokes are gray

### Jupyter Book MyST

[*Jupyter Book MyST*](https://mystmd.org/guide/quickstart-myst-markdown) is a interesting project that converts jupyter notebooks into PDF or Web sites.

- Callout & Admonition
- Executable Code Block with line highlight
- Cross-Ref Preview
